# Вспомогательный скрипт для работы с файлами сэмплера

### Объединение отдельных паттернов в полноценный мультитрек
<img width="1183" height="698" alt="Снимок экрана 2025-11-10 в 16 38 48" src="https://github.com/user-attachments/assets/863142e0-51a2-4e3b-a0de-dcf00f0a686f" />

Запустить локальный интерфейс:
```
./waver
```

После запуска откроется браузер с локальным UI.

Использовать через терминал без UI:
```
waver comb "путь к папке с паттернами"
```

Явно запустить локальный интерфейс из терминала:
```
waver ui
```

Собрать бинарник для macOS/Linux:
```
go build -o waver ./cmd/comb404
```

Собрать бинарник для Windows:
```
go build -o waver.exe ./cmd/comb404
```

Пример для Windows:
```
.\waver comb "E:\PROJECT_07\"
```

Пример для Mac:
```
./waver comb "/FLASH/PROJECT_08"
```

Итоговые файлы будут лежать рядом с waver в папке out
